### Project Description

A console application demonstrating **15 real-world LINQ queries** on a large dataset of international football matches (~13,000 games from 2010–2024).  
The project is designed to master **method-based LINQ syntax** including filtering, projection, grouping, sorting, aggregation, and advanced operations.

---

### Dataset

- **File:** `data/results_2010.json`
- **Source:** [martj42/international-football-results](https://github.com/martj42/international-football-results-from-1872-to-2017)
- **Records:** ~13,049 matches
- **Key fields:** `Date`, `Home_team`, `Away_team`, `Home_score`, `Away_score`, `Tournament`, `City`, `Country`, `Neutral`
